연동 해제

연결을 해제하면 이 브라우저에서 동기화가 중단됩니다. 데이터는 삭제되지 않습니다.

배포 가이드

  1. 구글 시트에서 확장 프로그램 → Apps Script 열기
  2. 제공된 코드를 붙여넣고 initSheet 실행 (최초 1회)
  3. 상단 메뉴 배포 → 새 배포 클릭
  4. 유형: 웹 앱 / 실행 계정: 나 / 액세스: 모든 사용자
  5. 생성된 웹앱 URL을 위 입력칸에 붙여넣고 저장
